# Restaurant Review Classification

## Project Overview
This project is a Restaurant Review Classification system that predicts whether a restaurant review is Positive or Negative using Natural Language Processing (NLP) and Machine Learning.

## Features
- Cleans and preprocesses restaurant reviews
- Converts text into numerical features using CountVectorizer
- Predicts sentiment as Positive or Negative
- Built with Python and Flask

## Technologies Used
- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- Flask

## Project Files
- Restaurant_Review_Classification.ipynb
- Restaurant_Reviews.tsv
- app.py
- restaurant_model.pkl
- cv.pkl
- requirements.txt

## How to Run

1. Install the required libraries:
   ```
   pip install -r requirements.txt
   ```

2. Start the Streamlit application:
   ```
   Streamlit run app.py
   ```

3. Open the application in your browser
